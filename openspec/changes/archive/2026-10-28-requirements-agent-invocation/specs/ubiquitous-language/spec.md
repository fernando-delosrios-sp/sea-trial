## ADDED Requirements

### Requirement: Materials Drop Thread term

The glossary SHALL define **Materials Drop Thread** as a pinned Slack message in a TES Event Channel dedicated to receiving requirements documents and kickoff files, where thread replies and file attachments automatically invoke the Requirements Agent.

#### Scenario: Materials Drop Thread term in glossary

- **GIVEN** this change archives
- **WHEN** the ubiquitous-language spec is updated
- **THEN** a Materials Drop Thread term entry SHALL exist with definition, context, and aliases

### Requirement: Agent Sub-Command term

The glossary SHALL define **Agent Sub-Command** as an explicit identifier following the `@Sea Trial` bot mention (e.g. `@Sea Trial requirements` or `@Sea Trial delivery`) that routes the invocation to the corresponding domain agent.

#### Scenario: Agent Sub-Command term in glossary

- **GIVEN** this change archives
- **WHEN** the ubiquitous-language spec is updated
- **THEN** an Agent Sub-Command term entry SHALL exist with definition, context, and usage rules

### Requirement: Requirements Refinement Thread term

The glossary SHALL define **Requirements Refinement Thread** as an interactive Slack message thread where the Requirements Agent and users converse to clarify scope, review deliverable candidates, and trigger Deliverables List writes.

#### Scenario: Requirements Refinement Thread term in glossary

- **GIVEN** this change archives
- **WHEN** the ubiquitous-language spec is updated
- **THEN** a Requirements Refinement Thread term entry SHALL exist with definition, context, and aliases
